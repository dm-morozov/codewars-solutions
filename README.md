# Codewars Solutions

В этом репозитории я решаю задачи (kata) с Codewars.

Основная цель — ежедневная практика, развитие алгоритмического мышления и поддержание навыков программирования.

## Языки

Основной язык:

- Python (приоритет, развиваюсь как Python-разработчик)

Дополнительно:

- TypeScript (использую для практики типизированного подхода)
- JavaScript ( реже, для сравнения и гибкости)

TypeScript для меня приоритетнее JavaScript, так как это типизированный язык и позволяет писать более надёжный код.

В Python также использую аннотации типов (`typing`), чтобы делать код чище и понятнее.

## Codewars подход

На Codewars задачи представлены в формате kata с уровнями сложности:

- 8–7 kyu — базовые задачи
- 6–5 kyu — средний уровень
- 4 kyu и выше — продвинутые задачи

Я стараюсь постепенно двигаться от простого к более сложному.

## Как я решаю задачи

- Сначала решаю задачу самостоятельно
- Не копирую чужие решения
- Стараюсь понять логику и подход
- После решения изучаю другие варианты
- Переписываю решение, если нахожу более элегантный способ

Иногда добавляю комментарии на русском и английском.

## Структура репозитория

Задачи могут быть организованы:

- по уровням сложности (kyu)
- или по темам

Примеры:

- 8_kyu
- 7_kyu
- 6_kyu
- strings
- math
- arrays
- fundamentals

## Формат решений

Каждый файл обычно содержит:

- название задачи
- уровень (kyu)
- теги (если есть)
- оценку сложности (Time / Space)
- краткую идею решения

Пример:

```python
# Reverse String
# Kyu: 8
# Tags: Strings, Fundamentals
# Time: O(n)
# Space: O(n)
```
